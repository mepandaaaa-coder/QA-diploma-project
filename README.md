# QA Diploma Project
# Автоматизированное тестирование веб-приложения Kinopoisk с применением паттерна Page Object Model

Проект представляет собой дипломную работу, посвященную разработке и внедрению автоматизированного тестового фреймворка для функционального тестирования пользовательского интерфейса (UI) и программного интерфейса (API) веб-приложения Kinopoisk.

---

## 🛠 Технологический стек
- **Python** (версия 3.14+)
- **Selenium WebDriver**
- **Pytest**
- **Allure Pytest**
- **Requests**

---

## 📦 Установка зависимостей

Перед запуском тестов убедитесь, что у вас установлены все необходимые библиотеки.
Вы можете установить их одной командой с помощью файла `requirements.txt`:

```bash
pip install -r requirements.txt

---

## 🚀 Запуск тестов для формирования отчета

pytest --alluredir=allure-results

---

## 📊 Просмотр сформированного отчета

allure serve allure-results
